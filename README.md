# Vehicle_Rentel_App

Downloard the Zip folder to your computer and open it using Visual Studio code, and Open the terminal type "cd client" and
after type "npm i" and after type "npm run dev" . Click the link and open the web app. After that get a new terminal and type "cd server" and type "npm i" and after type "npm start" , it will automatically start the backend service.


User Authentication: Secure login and signup functionalities, including JWT (JSON Web Tokens) for session management.
CRUD Operations: Users can Create, Read, Update, and Delete resources in the app.
Booking System: Enables users to book vehicles, including checking availability and managing reservations.

Tools and Technologies:
 MERN Stack:
       MongoDB
       Express.js
       React
       Node.js

 Vite: Frontend build tool and development server for a fast and optimized development experience.
 
Authentication:
       jsonwebtoken: For generating and verifying JWTs 

Version Control:
       Git: For version control.
       GitHub: For hosting the repository.
